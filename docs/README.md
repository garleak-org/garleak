# Documentation

This directory holds documentation for people who run Garleak and people who contribute
to it.

## Here

- [HOSTING.md](HOSTING.md) compares the free hosting options, says why GitHub Pages comes
  first and when to move to Cloudflare, gives the DNS steps at Namecheap, and lists the
  other free services the project uses.

## Elsewhere in the repository

- [../MASTER-PLAN.md](../MASTER-PLAN.md) explains what Garleak is and why.
- [../SPEC.md](../SPEC.md) defines the objects, stages, assistance axes, and versions.
- [../DESIGN.md](../DESIGN.md) is the visual and copy brief.
- [../BUILD-PLAN.md](../BUILD-PLAN.md) is the milestone plan with acceptance criteria.
- [../CLAUDE.md](../CLAUDE.md) lists the invariants and conventions for anyone writing
  code here.
- `../archive/FORMAT.md` documents the record format (written with the generator).
- [../rfcs/README.md](../rfcs/README.md) describes how the instrument changes, and
  [RFC 0001](../rfcs/0001-static-architecture.md) records the move to a static site.
- [../attic/README.md](../attic/README.md) describes the retired dynamic stack.
